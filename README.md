# Мої слова · v3.5.0

Оновлення додає необов’язкові вправи з реченнями через Groq та Supabase Edge Function check-sentence. Наявні слова, прогрес, JSON-копії й синхронізація залишаються.

Для встановлення потрібні секрет GROQ_API_KEY у Supabase, SQL із комплекту налаштування та функція check-sentence. Повна інструкція й кнопки копіювання — у START-HERE.html окремого комплекту vocabulary-sentences-setup-v3.5.0.zip. Секретів у цих файлах немає; ніколи не додавай ключ Groq до репозиторію.

У Практиці можна вимкнути «Іноді складати речення з ШІ». Запит до ШІ створює тільки кнопка «Перевірити речення». Помилки й пропуски цієї вправи не впливають на прогрес слова. Для звичайної практики ШІ та постійний інтернет не потрібні.

Щоб оновити GitHub Pages, завантаж вміст папки з index.html поверх старих файлів у корені репозиторію, а не саму папку. Дочекайся публікації та підтвердь оновлення на обох пристроях. Версія в Налаштуваннях: v3.5.0.
