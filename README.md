# Мої слова · v3.1.0

Компактний vocabulary quiz для iPhone і Mac із синхронізацією Supabase.

Нове: необов’язкові приклади речень англійською й українською та примітка до картки. Їх видно у Словнику через «Приклад і примітка» та в квізі після перевірки відповіді. Редагування: ⋯ → Редагувати → «Приклад і примітка». Приклади включено в локальне збереження, синхронізацію, конфлікти й JSON-копії. Старі копії без цих полів читаються.

Перед публікацією виконай 01-add-examples.sql у SQL Editor свого наявного проєкту Supabase (скрипт у комплекті оновлення). Потім завантаж вміст цієї папки в корінь існуючого репозиторію та дочекайся GitHub Pages. У застосунку підтвердь «Оновити застосунок». У Налаштуваннях має бути v3.1.0.

Адреса сайту, ключі локального словника й сеансу залишилися ті самі. Не очищай Safari і не видаляй іконку PWA для оновлення. Перед оновленням синхронізуй та збережи JSON.

Без інтернету працюють уже завантажені картки та квіз; непередані локальні зміни синхронізуються після повернення інтернету й відкриття застосунку. Підсумки квізу залишаються на пристрої. Хмарний словник не замінює резервної копії.

Mac-помічник публікувати на GitHub Pages не потрібно. Після входу в акаунт словника він записує тільки картки, підтверджені кнопкою «Додати до словника». Генерація відбувається на Mac через ChatGPT; на сайт його облікові дані не передаються.

Публікувати можна як звичайний статичний сайт: GitHub Pages → Deploy from branch → main → /(root). Пакети й збірка не потрібні. Папка icons має залишатися поряд із index.html. config.js містить лише публічні параметри Supabase.
