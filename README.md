# Мої слова · v3.2.0 — ручні позначки

У формі додавання/редагування є блок «Позначка картки»: Без позначки / Слово / Фразове дієслово / Вираз. Позначку обираєш сам, автоматичного розпізнавання немає. Одночасно можна вибрати один тип. Старі картки залишаються без позначки.

Позначка показується біля слова у Словнику, зберігається локально, у Supabase та в JSON-копіях. Тип можна змінити чи прибрати через ⋯ → Редагувати. Конфлікти різних позначок між пристроями показуються в Налаштуваннях, як звичайні конфлікти карток.

## Оновлення з v3.1.0

1. На сайті синхронізуй слова й збережи JSON-копію.
2. Supabase → SQL Editor → + → Create a new snippet. Встав ВЕСЬ SQL нижче та натисни Run. Очікується Success. Скрипт додає поле й обмеження, не видаляє наявні слова та не змінює правила доступу до власних рядків. Потрібна вже наявна таблиця vocabulary_words із RLS.
3. Розпакуй ZIP сайту. ВІДКРИЙ папку з index.html, app.js, sw.js та icons у Finder. Натисни ⌘ + A усередині неї. На ГОЛОВНІЙ сторінці репозиторію my-vocabulary вибери Add file → Upload files і перетягни вибраний ВМІСТ. У списку має бути index.html, а не website/index.html чи vocabulary-labels/index.html. Commit changes → дочекайся GitHub Pages.
4. Відкрий словник на Mac та iPhone з інтернетом, підтвердь «Оновити застосунок». У Налаштуваннях має бути v3.2.0. Не видаляй іконку й не очищай Safari.

```sql
begin;
-- Existing cards stay unmarked until you choose a label yourself.
alter table public.vocabulary_words
  add column if not exists category text not null default '';

do $$ begin
  if not exists (select 1 from pg_constraint where conname='vocabulary_category_values'
    and conrelid='public.vocabulary_words'::regclass) then
    alter table public.vocabulary_words add constraint vocabulary_category_values
      check (category in ('','word','phrasal_verb','expression'));
  end if;
end $$;

grant insert (category), update (category)
  on public.vocabulary_words to authenticated;
notify pgrst, 'reload schema';
commit;
```

## Перевірити після оновлення

Словник → ⋯ біля give up (або будь-якої потрібної картки) → Редагувати → Фразове дієслово → Зберегти. Позначка має з’явитися під англійським словом. Синхронізуй і перевір картку на іншому пристрої. Потім відкрий її редагування: твій вибір має залишитися. Вибір «Без позначки» прибирає позначку після збереження.

Mac-помічник оновлювати не потрібно. Ця функція працює вручну в самому словнику. Картки, додані старим помічником, будуть без позначки; її можна встановити на сайті.

## Перевірка розробником

19 жовтня 2026: пройдено 4 групи автоматичних перевірок (старі/нові JSON і дублікати імпорту; обмін змінами позначок та конфлікти; REST-серіалізація з owner/revision; фактичні обробники додавання/редагування форми й відображення позначки на моделі DOM). Також перевірено синтаксис app.js. Мережеві відповіді штучні, особистий хмарний словник не змінювався. Живий SQL і вигляд на iPhone потребують перевірки після публікації.

У незапакованому комплекті: node --test tests/labels.test.mjs (Node.js 22+). У ZIP для публікації лише файли сайту; тести й SQL як окремі файли туди не включені.
